# Mon Portfolio

Ce dépôt contient le code source de mon site portfolio personnel : une vitrine de mes projets, mes expériences, mes activités et mes aspirations professionnelles.

Site en ligne : *https://roderick-darell.github.io/*

## 🎯 À propos de ce site

Ce portfolio me permet de présenter :
- Qui je suis et mon parcours
- Mes expériences professionnelles
- Mes compétences et centres d'intérêt
- Mes projets et réalisations
- Un moyen de me contacter

## 🚀 Démarrage rapide

### Prérequis
- Node.js 20.19+ ou 22.12+

### Installation
```bash
# Cloner le dépôt
git clone <url-du-repo>
cd portfolio

# Installer les dépendances
npm install

# Lancer le serveur de développement
npm run dev

# Build pour la production
npm run build
```

## 🛠️ Stack technique

- **Vite** – Outil de build et serveur de développement
- **LESS** – Préprocesseur CSS
- **JavaScript vanilla** – Sans framework, modules ES6
- **Données au format JSON** – Contenu éditable facilement (`public/api/*.json`)

## 📁 Organisation

- `public/api/` – Fichiers JSON contenant le contenu du site (à propos, expériences, projets, liens...)
- `src/styles/` – Fichiers LESS pour le style
- `src/js/` – Scripts JavaScript
- `public/img/` – Images du site

## 🛠️ Commandes utiles

```bash
npm run dev      # Serveur de développement
npm run build    # Build de production
npm run preview  # Prévisualiser le build de production
```
